# Contributing to NOYRAEX

Thank you for your interest in contributing to NOYRAEX.

NOYRAEX is an open-source project, and everyone is welcome to help improve the ecosystem.

## How You Can Help

You can contribute as:

- Developer
- UI/UX Designer
- Designer
- Writer
- Translator
- Tester
- Community contributor

## Ways to Contribute

You can help by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Creating designs
- Writing code
- Testing improvements

## Before Contributing

Before making changes:

1. Check existing Issues.
2. Discuss large ideas before starting work.
3. Keep changes focused and clear.

## Pull Requests

When submitting a Pull Request:

- Explain what you changed.
- Keep commits understandable.
- Make sure your changes do not break existing features.

Thank you for helping build NOYRAEX.
